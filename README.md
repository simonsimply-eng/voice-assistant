# העוזר הקולי · Voice Assistant

שולחים הודעה קולית בוואטסאפ – והעוזר רושם משימות, פגישות ותזכורות. שום דבר לא נשמר בלי "כן" שלך.
Send a WhatsApp voice note – it saves tasks, meetings and reminders. Nothing is saved without your "yes".

**התקנה / Install:** https://simonsimply-eng.github.io/voice-assistant/

- אנדרואיד 10 ומעלה · Android 10 or newer
- ההקלטות מתומללות בטלפון עצמו · Voice notes are transcribed on the phone itself
- אפשר לבחור ששום דבר לא יוצא מהמכשיר · You can choose that nothing leaves the device

This repository holds only the install file and its page. The source code is private.
